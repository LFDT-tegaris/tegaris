# Code of Conduct

This project follows the [LF Decentralized Trust Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct).

Treat other participants with respect, keep discussions constructive and make room for different experience levels and perspectives.

Use the reporting procedure in the LFDT Code of Conduct for conduct concerns. Security vulnerabilities should be reported through [SECURITY.md](SECURITY.md).
